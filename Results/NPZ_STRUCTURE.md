# NPZ Prediction & Result File Specification

This document defines the exact schema, array keys, shapes, and data types stored in the compressed NumPy result archives (`results_{zone}_full4sets_2024.npz`) for each delivery area (`DE1`, `DE2`, `DE3`, `DE4`).

All files are located in `Results/annual_run_2024/` and generated by [`run_experiment.py`](file:///home/mat/Dokumente/Delivery%20Area%20EPF/run_experiment.py) via `np.savez_compressed`.

---

## 1. Storage Location & Naming

| File Pattern | Description |
| :--- | :--- |
| `Results/annual_run_2024/results_{zone}_full4sets_2024.npz` | Canonical 2024 annual test results ($N = 35{,}132$ quarter-hours) for `{zone}` $\in \{\text{DE1}, \text{DE2}, \text{DE3}, \text{DE4}\}$. |

---

## 2. Array Schema & Keys

### 2.1 Core Ground-Truth & Calendar Arrays

| Key | Shape | Dtype | Description |
| :--- | :--- | :--- | :--- |
| `dates` | `(N,)` | `str / <U10` | Calendar dates (`"YYYY-MM-DD"`) for each 15-min interval ($N = 35{,}132$) |
| `dates_daily` | `(n_days,)` | `str / <U10` | Unique calendar dates ($n_{\text{days}} = 366$ for leap year 2024) |
| `qh_idx` | `(N,)` | `int16` | Quarter-hour index ($0 \dots 95$) within the delivery day |
| `y_true` | `(N,)` | `float32/64` | Realized target price $\text{VWAP}_{\text{0to30}}$ in EUR/MWh |
| `benchmark` | `(N,)` | `float32/64` | Canonical naive benchmark price $\text{VWAP}_{\text{90to105}}$ in EUR/MWh |
| `y_true_2d` | `(n_days, 96)` | `float64` | 2D matrix of realized prices |
| `benchmark_2d` | `(n_days, 96)` | `float64` | 2D matrix of naive benchmark prices |

---

### 2.2 Linear Benchmark (LASSO)

Stored for all 4 feature sets (`st` $\in \{\text{s1}, \text{s2}, \text{s3}, \text{s4}\}$):

| Key | Shape | Dtype | Description |
| :--- | :--- | :--- | :--- |
| `pred_lasso_{st}` | `(N,)` | `float32` | Standard LASSO predictions on Set `{st}` |
| `pred_lasso_{st}_2d` | `(n_days, 96)` | `float64` | 2D reshaped predictions on Set `{st}` |
| `pred_lasso_ens_pure` | `(N,)` | `float32` | Rolling inverse-MAE ensemble over sets S1+S2+S3+S4 |
| `pred_lasso_ens_pure_2d` | `(n_days, 96)` | `float64` | 2D matrix of LASSO pure ensemble |

---

### 2.3 cSVR Predictions & Ablation (Puć & Janczura, 2024)

Stored for all 4 feature sets (`st` $\in \{\text{s1}, \text{s2}, \text{s3}, \text{s4}\}$):

| Key | Shape | Dtype | Description |
| :--- | :--- | :--- | :--- |
| `pred_csvr_{st}` | `(N,)` | `float32` | cSVR predictions with correlation filter ($|r| \ge 0.80$ on S1, $|r| \ge 0.95$ on S2) |
| `pred_csvr_{st}_2d` | `(n_days, 96)` | `float64` | 2D reshaped cSVR predictions |
| `pred_csvr_ens_pure` | `(N,)` | `float32` | **Pure cSVR Ensemble** over S1+S2+S3+S4 (Puć & Janczura standard) |
| `pred_csvr_ens_pure_2d` | `(n_days, 96)` | `float64` | 2D matrix of Pure cSVR ensemble |
| `pred_csvr_nocorr_{st}` | `(N,)` | `float32` | cSVR ablation predictions without correlation filter |
| `pred_csvr_nocorr_{st}_2d` | `(n_days, 96)` | `float64` | 2D matrix of cSVR ablation |
| `pred_csvr_nocorr_ens_pure` | `(N,)` | `float32` | Pure cSVR ensemble without correlation filter |
| `pred_csvr_nocorr_ens_pure_2d`| `(n_days, 96)` | `float64` | 2D matrix of cSVR no-filter ensemble |

---

### 2.4 MAML-NN Predictions & Deep Ensembles (Finn et al., 2017)

Stored for each configured bypass mode (`mode` $\in \{\text{"nobypass"}, \text{"optlasso"}\}$), all sets (`st` $\in \{\text{s1}, \text{s2}, \text{s3}, \text{s4}\}$), and seeds (`sd` $\in \{42, 123, 999\}$):

| Key | Shape | Dtype | Description |
| :--- | :--- | :--- | :--- |
| `pred_maml_{mode}_{st}_seed{sd}` | `(N,)` | `float32` | Individual MAML-NN seed prediction |
| `pred_maml_{mode}_{st}` | `(N,)` | `float32` | Primary seed run (`seed=42`) |
| `pred_maml_{mode}_{st}_2d` | `(n_days, 96)` | `float64` | 2D matrix of primary seed run |
| `pred_maml_{mode}_deep_{st}` | `(N,)` | `float32` | **Deep Ensemble mean** across 3 seeds for Set `{st}` |
| `pred_maml_{mode}_deep_{st}_2d` | `(n_days, 96)` | `float64` | 2D matrix of Deep Ensemble per set |
| `pred_maml_{mode}_ens_pure` | `(N,)` | `float32` | Single-seed rolling inverse-MAE ensemble over S1+S2+S3+S4 |
| `pred_maml_{mode}_ens_pure_2d` | `(n_days, 96)` | `float64` | 2D matrix of single-seed MAML ensemble |
| `pred_maml_{mode}_deep_ens_pure` | `(N,)` | `float32` | **Deep Ensemble across seeds AND sets S1–S4** (Primary Deep Architecture) |
| `pred_maml_{mode}_deep_ens_pure_2d`| `(n_days, 96)` | `float64` | 2D matrix of Deep Ensemble across sets |

## 3. Evaluation & Usage Examples

### 3.1 Loading and Comparing Ensembles (Strict 1:1 Benchmark)
```python
import numpy as np

# Load canonical 2024 results for Amprion (DE2)
data = np.load("Results/annual_run_2024/results_DE2_full4sets_2024.npz")

y_true = data["y_true"]
bm = data["benchmark"]

# Model predictions
p_csvr_ens = data["pred_csvr_ens_pure"]
p_maml_deep = data["pred_maml_nobypass_deep_ens_pure"]

# Compute MAE
mae_naive = float(np.mean(np.abs(y_true - bm)))
mae_csvr  = float(np.mean(np.abs(y_true - p_csvr_ens)))
mae_maml  = float(np.mean(np.abs(y_true - p_maml_deep)))

print(f"Naive Benchmark MAE:     {mae_naive:.4f} EUR/MWh")
print(f"Pure cSVR Ensemble MAE:  {mae_csvr:.4f} EUR/MWh  (rMAE: {mae_csvr / mae_naive:.4f})")
print(f"Deep MAML Ensemble MAE:  {mae_maml:.4f} EUR/MWh  (rMAE: {mae_maml / mae_naive:.4f})")
```

### 3.2 Multivariate Diebold-Mariano Test (Ziel & Weron, 2018)
```python
from Models.ensemble import dm_test

# Daily-vector DM test comparing Deep MAML-NN against cSVR (HAC lag h=7)
dm_stat, p_val = dm_test(y_true, p_maml_deep, p_csvr_ens, h=7)

print(f"DM Statistic: {dm_stat:.4f} (p-value: {p_val:.4e})")
if dm_stat < -1.96:
    print("MAML-NN significantly outperforms cSVR at 5% significance.")
elif dm_stat > 1.96:
    print("cSVR significantly outperforms MAML-NN at 5% significance.")
else:
    print("No statistically significant difference between models.")
```
